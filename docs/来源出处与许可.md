# 来源出处参考 · 许可说明

本仓库（`DeltaFORCE_harmonica`）是把《三角洲行动》口琴玩法的谱面自动演奏工具，
**照搬以下公开开源实现与公开规范后移植 / 优化**而成的。所有上游作品的著作权归其原作者，
本仓库对移植部分保留其原始许可与版权声明。

## 一、上游来源（必读）

### 1. ChickenD233/midikey-player —— 主要移植来源（MIT）

* 上游地址：<https://github.com/ChickenD233/midikey-player>
* 说明：原仓库 `ChickenD233/harmonica-auto-player` 已被投诉下架，作者迁移为 `midikey-player`（本仓库移植以迁移版为准）。
* 许可：**MIT License**，版权行 `Copyright (c) 2026 ChickenD233`（见上游根目录 `LICENSE`，另有 `THIRD-PARTY-NOTICES.md`）。
* 本仓库移植的具体内容：

| 上游位置 | 移植到 | 内容 |
|---|---|---|
| `KeymapProfile.BuildChromatic8()` | `keymap.py` | 8 键半音键位表（`Z X C V B N M ,` ↔ `1 2 3 4 5 6 7 高音1`），鼠标左/中/右 = 降八度 / 升半音 / 升八度 |
| `NoteMapper.cs` | `keymap.py` | 「音高 → 键 + 变调键」查找，绝对音高映射（不静默移调） |
| `MidiLoader.cs` | `midi_in.py` | 标准 MIDI 文件读法：音轨挑选、和弦取最高音、打击乐轨剔除 |
| **`Engine/InputTiming.cs`** | `play.py` | **逐帧采样时序口径：修饰键比音键早 40ms；前音抬起→后音按下 ≥40ms；最短按住 45ms**（60fps ≈16.7ms/帧） |
| `MacroExporter.cs` | `macros.py` | 宏导出结构与「误差进位」处理 |

### 2. ChiZhou6/harmonica-visualizer —— 文本谱格式与可视化（上游未见许可证文件）

* 上游地址：<https://github.com/ChiZhou6/harmonica-visualizer>
* 借鉴内容：`BPM=` / `TITLE=` 文本谱格式；**DFH 三行小节谱**（简谱 / 键位 / 节奏）解析；`b` / `#` / `^` 变调前缀语义；可视化提示条思路（→ `hud.py`）。
* 许可状态：上游仓库**未见许可证文件**。因此本仓库**只做文字出处标注与格式兼容实现，不分发上游任何文件**。

### 3. jiko-official.top · Delta 口琴工具站 —— 简谱 DSL 权威口径

* 站点地址：<https://jiko-official.top/delta/>
* 借鉴内容：简谱 DSL 全套语法与语义（`5` = 1 拍、`5_` = 半拍、`5-` = 2 拍、`5--` = 3 拍、`0` = 休止、`.` 附点、`#` / `b`、`'` / `,` 高低八度、`~` 连音、`L`/`M`/`R` 变调前缀（`PREVIEW_OFFSETS = {L:-12, M:+1, R:+12}`）、`||:` / `:||` 反复、`:` / `/` 精确拍数写法）；气口常量（`INPUT_TRANSITION_GAP_MS = 18`、`MIN_NOTE_HOLD_MS = 24`、`waitMs`）；站点曲库曲目。
* 许可状态：站点公开内容，版权归站点所有。本仓库**只做文字出处标注与 DSL 兼容实现，不分发站点资源文件**。

## 附：两个第三方曲库目录（2026-09 接入）

本项目新增 `songlib.py`，按歌名跨站检索，**只用公开接口/公开页面**：

### 1. shushu.fan · 口琴曲谱（三角洲鼠鼠工具）
* 站点：https://shushu.fan/fun/harmonica
* 取数方式：解析该公开页面 SSR 载荷（Next.js RSC）里的曲目目录（2026-09 实取 195 首，仍在增长）
  （字段：songId / title / authorName / bpm / difficulty / durationMs / pitchMin / pitchMax / notesPerSecond）。
* 谱面本体：其接口需登录（`/api/harmonica/*` 返回"未登录"），**本项目不做任何绕过**——
  只给出该曲的直达链接 `https://shushu.fan/fun/harmonica/<songId>`；
  用户在页面里复制谱面文本后，可用 `python play.py --paste` 直接弹。

### 2. delta-test.shallow.ink · DeltaForce 口琴曲库
* 站点：https://delta-test.shallow.ink/harmonica ；公开接口：`https://delta-test-api.shallow.ink`
* 取数方式：走它**自己网页端用的同一套公开机制**——`POST /api/v1/auth/anonymous-token`
  带一个本地随机生成的设备指纹（存在 `~/.harmonica_config.json` 的 `device_id`），
  拿到 `anon_…` 匿名令牌后带 `X-Anonymous-Token` 调
  `GET /api/v1/df/harmonica/songs?page=&pageSize=`（2026-09 实取 196 首，仍在增长；
  字段与上表相同 + playCount）。
* 谱面本体：不在公开接口里（曲谱是作为媒体文件上传、由站内播放器消费），**本项目不做抓取**——
  只给出直达链接 `https://delta-test.shallow.ink/harmonica/<songId>`，同样可用 `--paste`。

> 说明：两站的曲目 `songId` 相同（同一数据库的两个前端）。
> 本地只缓存**目录元数据**到 `_cache/`（可随时删除重建），**不缓存、不转载谱面内容**。
> 若站点方不希望被检索，请告知，会立刻移除对应适配器。
